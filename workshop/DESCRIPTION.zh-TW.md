[h1]帕魯技能 DPS 分析器[/h1]

[h2]測量什麼[/h2]
適用於 Windows 單人世界、Palworld 1.0 的傷害驗證工具。觀察帕魯技能對 Boss 實際造成的傷害、占比、DPS 與每次施放的命中段數；不是玩家排行榜，也不是只按面板威力排列技能強弱。
預設計算帕魯傷害，人物／武器傷害可另外開啟。普通野生帕魯與 PvP 不在支援的測試範圍。

[h2]安裝與開始測試[/h2]
[olist]
[*]訂閱本模組與 [url=https://steamcommunity.com/workshop/filedetails/?id=3625223587]UE4SS Experimental (Palworld)[/url]，在模組管理中啟用兩者，再完整重啟。無須安裝 PalSchema。
[*]進入世界按 [b]F3[/b]：野外、地城或塔主選「[b]野外／副本 Boss[/b]」；石板召喚的頭目選「[b]石板 Boss[/b]」。模式由你手動選擇。
[*]關閉 F3，按 [b]F2[/b] 清除舊結果並等待新測試。[b]從第一筆有效 Boss 傷害開始計時，不是按下 F2 就開始計時。[/b]
[*]讓帕魯攻擊對應 Boss。石板模式也納入自己公會符合條件的據點帕魯。預設手動模式持續累計，直到下次 F2 歸零；變更測試類型或傷害來源設定後，請按 F2 再開始下一場。
[/olist]

[h2]儀表、報表與設定[/h2]
[list]
[*]即時儀表顯示傷害、DPS 與技能占比，不將結果送進聊天室；只在 Palworld 位於前景時顯示。
[*]F3 提供「[b]設定[/b]」、「[b]分組百分比[/b]」、「[b]本次測試詳情[/b]」。詳情包含傷害／DPS、有傷與無傷施放、總命中段數，以及已結算施放的最低／平均／最高命中段數；零命中施放也納入計算。
[*]石板戰報只合併同種且完整三格配招相同的帕魯，以 ×N 顯示；不同配招分為 A、B 等組。無法讀取完整配招時獨立列出。
[*]石板儀表顯示傷害最高三組，每組最多三條技能占比；F3 可查看全部組別。
[*]F3 可調整儀表開關、位置、縮放與詳細程度。語言可跟隨遊戲或從 17 種語言中指定；也可選手動測試或依目標自動分場。
[/list]

[h2]如何解讀數字[/h2]
直接連結技能來源的傷害，與依有限證據「推定」的傷害會分開標示；證據不足時保留為未辨識，不以傷害大小或僅憑裝備技能猜測。部分延遲命中與持續傷害可能無法完整辨識。
命中統計代表觀察結果，不保證等於技能的理論全段命中。實際施放間隔包含 AI 選招與移動，不等同純冷卻時間。困難塔只計主要塔主，不計小怪。

[h2]人物／武器測試[/h2]
在 [b]F3「設定」[/b]開啟人物／武器傷害，再按 F2。為方便比較，每場測試全程使用同一種武器。可辨識的武器／投射物來源分開列出；無法辨識時保留未知標示。

[h2]相容性與問題回報[/h2]
目前公開版本 [b]v0.5.29[/b]，支援目標為 Windows 單人世界；多人與專用伺服器尚未驗證。遊戲或 UE4SS 更新後可能需要相容性修正。
儀表使用隨附的獨立 Windows 顯示程序，需要 Windows PowerShell 5.1 與 WPF，會隨遊戲結束而關閉。若安全軟體阻擋，可能仍有傷害紀錄，但不顯示儀表。
回報時請附遊戲／模組版本、受影響的技能或測試步驟，以及相關 UE4SS.log 片段。
