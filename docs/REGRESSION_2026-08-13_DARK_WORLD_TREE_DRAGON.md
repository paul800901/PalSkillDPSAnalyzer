## 根因與修正

- `SkillMetadataFallbacks` 沒有三個暗系技能，無 Waza／DamageCauser 的固定倍率命中無法使用三格裝備唯一簽名。
- 450／8 對應暗黑雷射、600／8 對應黑暗之擁、30／8 對應劇毒射擊；全部限定在該帕魯實際三格裝備內使用。
- 40／8 繼續保留為普攻「暗能彈」，不得被暗系主動技能搶走。
- 中毒狀態是獨立傷害來源；沒有狀態施加者證據時，不把不明傷害偽裝成劇毒射擊。

## 回歸門檻

同一隻帕魯裝備 `DarkLaser / DarkLegion / PoisonShot` 時：

1. 450／8 必須進暗黑雷射。
2. 600／8 必須進黑暗之擁。
3. 30／8 必須進劇毒射擊本體。
4. 即使另一個裝備技能正處於目前動作，上述唯一簽名也不得變成未辨識。
5. 40／8 必須維持「普攻｜暗能彈」。
6. 四列加總必須等於整場總傷；中毒狀態若未被 collector 捕捉，需明示限制而非猜測。
