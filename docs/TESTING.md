# 測試說明

## 離線測試

在專案根目錄執行：

```powershell
powershell -ExecutionPolicy Bypass -File .\tests\run_all.ps1
```

測試不存取 Palworld 程序或遊戲檔案，涵蓋：

- Lua 語法、UTF-8、工作坊結構與相依項目。
- 傷害回呼不直接存取 UObject。
- Boss 擊殺、捕捉、逾時與複合 Boss 生命週期。
- 帕魯、騎乘技能與人物武器的來源歸屬。
- 人物傷害預設關閉及可選開啟。
- 同一技能／武器候選的傷害與命中聚合。
- 不同技能欄位或投射物分成不同候選。
- 未知候選不被猜測命名。
- 10,000 次傷害佇列壓力與結束事件保留。

## 第一次實機診斷

1. 只啟用一隻已知技能配置的帕魯。
2. 對一個普通野外 Boss 使用 2–3 個技能。
3. 完成戰鬥後，從 `UE4SS.log` 擷取本 Mod 的行。
4. 檢查 `damage-schema` 是否提供技能欄位。
5. 檢查 `damage-sample` 與 `diagnostic-candidate` 是否能分開各技能。
6. 對持續傷害、多段傷害與無投射物近戰技能各做一次驗證。

離線測試不能證明 Palworld 實際反射結構；完成上述讀回前，狀態只能標示為「本機離線驗證」。
